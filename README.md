# Actividad Clase 10 — Patrones de Diseño

Repositorio correspondiente a la **Clase 10 de Programación Avanzada (189)** de la Licenciatura en Ciencia de Datos — UNAB.

## Actividad

La actividad práctica consiste en investigar e implementar patrones de diseño. Los ejercicios se encuentran organizados en carpetas según su número.

## Estructura

```
actividad_clase10/
├── ejercicio_1/   # Críticas a los patrones de diseño con ejemplos concretos
└── ejercicio_2/   # Implementación de 3 patrones de diseño en Python
    ├── factory_method.py   # Patrón Creacional — Sistema de notificaciones
    ├── adapter.py          # Patrón Estructural — Integración de pasarelas de pago
    └── mediator.py         # Patrón de Comportamiento — Sala de chat con bot
├── ejercicio_3/   #  Ejemplos concretos de patrones de diseño aplicados a la vida real.
├── ejercicio_4/   #  Alias de patrones de diseño.
└── ejercicio_5/   #  Antipatrones de diseño.


```

## Patrones implementados (Ejercicio 2)

| Patrón         | Categoría      | Ejemplo implementado                         |
| -------------- | -------------- | -------------------------------------------- |
| Factory Method | Creacional     | Sistema de notificaciones (Email, SMS, Push) |
| Adapter        | Estructural    | Pasarelas de pago (PayPal, MercadoPago)      |
| Mediator       | Comportamiento | Sala de chat con bot asistente               |

## Ejecución

```bash
python ejercicio_2/factory_method.py
python ejercicio_2/adapter.py
python ejercicio_2/mediator.py
```
